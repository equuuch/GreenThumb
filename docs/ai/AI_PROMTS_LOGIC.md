# Логика взаимодействия с ИИ

Настоящий документ описывает структуру запросов к GigaChat API и алгоритмы выбора моделей для обеспечения точности диагностики и экономии токенов

## 1. Системные инструкции (Prompts)

Все запросы используют ролевые модели для повышения качества ответов:

* **PROMPT_NORMALIZE**: роль эксперта-ботаника. используется для приведения пользовательского ввода к официальному биологическому названию. возвращает строгий JSON
* **PROMPT_GENERATE_PASSPORT**: роль профессионального агронома. генерирует технические характеристики для новых видов растений. возвращает JSON
* **PROMPT_AGRONOMIST**: роль дружелюбного помощника. используется для оперативных консультаций в чате
* **PROMPT_VISION_DIAGNOSIS**: роль визуального фитопатолога. анализирует фотографии на наличие болезней и вредителей
* **PROMPT_IDENTIFY_TO_ADD**: роль систематика. определяет вид растения по фотографии для первичной регистрации в базе

## 2. Оркестрация моделей

В системе реализовано автоматическое переключение между моделями семейства GigaChat:

* **GigaChat (Lite)**: используется для всех текстовых задач и генерации JSON. обеспечивает минимальную задержку и низкую стоимость запроса
* **GigaChat-Max**: используется исключительно для Vision-задач (обработка фото). обладает повышенной точностью распознавания визуальных признаков патологий

## 3. Температурный режим (Temperature)

Система динамически управляет «креативностью» модели:

* **0.1 (Strict)**: устанавливается для задач, требующих возврата JSON. это минимизирует галлюцинации и гарантирует корректный парсинг данных бэкендом
* **0.7 (Creative)**: устанавливается для чат-консультаций. обеспечивает естественный и живой язык общения с пользователем

## 4. Оптимизация и экономия ресурсов

* **RAM-сжатие**: перед отправкой в ИИ каждое изображение проходит через Image Pipeline (Pillow). фото уменьшается до 1024px, что снижает вес запроса в токенах на 60–80%
* **Кэширование**: OAuth-токен сохраняется в памяти на 30 минут с защитным интервалом в 60 секунд для предотвращения обрывов сессии
