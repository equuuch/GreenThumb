# AI_PROMTS_LOGIC.md

Логика взаимодействия с GigaChat API, структура запросов и алгоритмы выбора моделей для точности диагностики и экономии токенов.

## 1. Системные инструкции (Prompts)

Все запросы используют ролевые модели. В `prompts.py` зафиксированы жесткие ограничения по формату и длине ответов:

* **PROMPT_NORMALIZE**: роль эксперта-ботаника. используется для приведения пользовательского ввода к официальному биологическому названию. Возвращает строгий JSON `{"standard_name": "...", "is_plant": true}`.
* **PROMPT_GENERATE_PASSPORT**: роль профессионального агронома. генерирует технические характеристики для новых видов растений. Описание (`description`) должно быть не менее 3 полных предложений. Возвращает JSON.
* **PROMPT_AGRONOMIST**: роль дружелюбного помощника. используется для чат-консультаций. Максимальная длина ответа — 350 символов. Учитывает переданный контекст (вид и статус растения).
* **PROMPT_VISION_DIAGNOSIS**: роль визуального фитопатолога. анализирует фотографии на наличие болезней. Выдает вид, патологию и план лечения из 3 шагов. Лимит — 400 символов.
* **PROMPT_IDENTIFY_TO_ADD**: роль систематика. определяет вид растения по фотографии для первичной регистрации в базе. Возвращает полный JSON-паспорт.

## 2. Оркестрация моделей

Система автоматически переключается между моделями в зависимости от типа задачи:

* **GigaChat (Lite)**: используется для всех текстовых задач и генерации JSON. обеспечивает минимальную задержку и низкую стоимость запроса.
* **GigaChat-Max**: используется исключительно для Vision-задач (обработка фото). обладает повышенной точностью распознавания визуальных признаков патологий. Требует предварительной загрузки файла через `/files`.

## 3. Температурный режим (Temperature)

В методе `get_ai_response` реализовано динамическое управление «креативностью»:

* **0.1 (Strict)**: устанавливается для задач, требующих возврата JSON (если слово "JSON" есть в системном промпте). Это минимизирует галлюцинации и гарантирует корректный парсинг данных.
* **0.7 (Creative)**: устанавливается для чат-консультаций и диагностики. Обеспечивает естественный и живой язык общения.

## 4. Оптимизация изображений (Image Pipeline)

Перед отправкой в ИИ каждое фото проходит через `_optimize_for_ai` (библиотека Pillow):

* **конвертация**: приведение к формату RGB (удаление альфа-канала PNG).
* **изменение размера**: уменьшение до `Config.IMAGE_MAX_SIZE` (1024px) по длинной стороне с сохранением пропорций.
* **сжатие**: сохранение в JPEG с качеством 70%. Это снижает вес запроса в токенах на 60–80%.
* **загрузка**: отправка файла на сервер Сбера с параметром `purpose: general` для получения `file_id`.

## 5. Управление сессией и аудит

* **кэширование**: OAuth-токен сохраняется в памяти на 30 минут. Обновление происходит автоматически за 60 секунд до истечения срока.
* **очистка данных**: автоматическое удаление Markdown-разметки (символы ```json) из ответов ИИ перед парсингом.
* **логирование**: каждый запрос фиксируется в таблицах `ai_consultations` (текст) и `token_usage` (количество потраченных токенов).
* **безопасность**: запросы выполняются с `verify=False` для обхода проблем с национальными SSL-сертификатами в среде Python.
