# SETUP_GUIDE.md

Пошаговая инструкция по настройке локального окружения для разработки и тестирования проекта GreenThumb.

## 1. Системные требования

* **Python**: версия 3.10 или выше.
* **Fonts**: наличие файла DejaVuSans.ttf в папке `assets/fonts/` для корректной генерации PDF-отчетов с поддержкой кириллицы.
* **Assets**: наличие корневой папки `assets` в директории проекта для автоматического создания подпапок `plants` и `logs` сервисным слоем.
* **Dependencies**: актуальный список библиотек зафиксирован в файле `requirements.txt`.

## 2. Порядок установки

* **Виртуальное окружение**: создание изолированной среды для предотвращения конфликтов зависимостей:
```bash
python -m venv venv
venv\Scripts\activate  # для Windows
source venv/bin/activate  # для Linux/macOS
```
* **Установка библиотек**: загрузка всех необходимых компонентов через пакетный менеджер:
```bash
pip install -r requirements.txt
```

## 3. Конфигурация окружения (.env)

Необходимо создать файл `.env` в корневом каталоге и заполнить следующие параметры:

* **GIGA_CREDS**: авторизационный ключ GigaChat в формате base64.
* **GIGA_CLIENT_ID**: уникальный идентификатор клиента Сбера.
* **GIGA_SCOPE**: область доступа API (обычно GIGACHAT_API_PERS или GIGACHAT_API_CORP).
* **DATABASE_URL**: путь к файлу базы данных (по умолчанию `sqlite:///greenthumb.db`).
* **IMAGE_MAX_SIZE**: лимит размера изображения для отправки в ИИ (по умолчанию 1024).

## 4. Инициализация и запуск

* **База данных**: запуск скрипта `seed.py` для автоматического создания структуры таблиц через метод `init_db()` и первичного наполнения справочника `plant_catalog`.
* **Тестирование**: выполнение интеграционных тестов `backend_test.py` для проверки связи с API GigaChat и корректности работы SQLAlchemy.
* **Интерфейс**: запуск графической оболочки приложения командой:
```bash
flet run main.py
```

## 5. Важные технические замечания

* **SSL сертификаты**: все сетевые запросы в `ai_services.py` выполняются с параметром `verify=False` для обхода проблем с национальными сертификатами в среде Python.
* **Многопоточность**: база данных SQLite настроена на работу в многопоточном режиме (`check_same_thread=False`) для совместимости с асинхронным ядром Flet.
* **Хранение медиа**: все фотографии сохраняются в папку ассетов. В базе данных фиксируется только относительный путь, что позволяет Flet автоматически находить файлы.
* **Логирование**: в режиме отладки параметр `DB_ECHO` в конфигурации позволяет видеть все SQL-запросы в консоли приложения.
