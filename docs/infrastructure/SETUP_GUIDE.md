# Руководство по развертыванию 

Настоящий документ содержит пошаговую инструкцию по настройке локального окружения для разработки и тестирования проекта GreenThumb

## 1. Системные требования

* **Python**: версия 3.10 или выше
* **Шрифты**: наличие файла DejaVuSans.ttf в папке assets/fonts/ для корректной генерации отчетов
* **Зависимости**: актуальный список библиотек зафиксирован в файле requirements.txt

## 2. Порядок установки

1. **Создание виртуального окружения**:
```bash
python -m venv venv
venv\Scripts\activate  # для Windows
source venv/bin/activate  # для Linux/macOS
```
2. **Установка необходимых библиотек**:
```bash
pip install -r requirements.txt
```

## 3. Конфигурация окружения

Создайте файл `.env` в корневом каталоге проекта на основе шаблона `.env.example` и заполните обязательные переменные:

* **GIGACHAT_CREDENTIALS**: авторизационный ключ в формате base64
* **GIGACHAT_CLIENT_ID**: уникальный идентификатор клиента
* **DATABASE_URL**: путь к файлу базы данных (по умолчанию sqlite:///greenthumb.db)

## 4. Инициализация и запуск

1. **Наполнение справочника**:
Запустите скрипт для автоматического создания таблиц и загрузки базового набора растений:
```bash
python seed.py
```
2. **Проверка работоспособности**:
Выполните интеграционные тесты для подтверждения связи с ии и базой данных:
```bash
python backend_test.py
```
3. **Запуск графического интерфейса**:
```bash
flet run main.py
```

## 5. Важные замечания

* **База данных**: файл .db включен в список исключений git. при изменении структуры моделей необходимо удалить старый файл базы и запустить seed.py повторно
* **Логирование**: в режиме разработки в файле config.py активирован параметр DB_ECHO для визуального контроля sql-запросов в консоли
