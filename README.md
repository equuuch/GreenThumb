# 🌿 GreenThumb – Интеллектуальная экосистема для ухода за растениями

**GreenThumb** – современное программное решение, объединяющее возможности нейросетевых моделей **GigaChat** и автоматизированные алгоритмы контроля жизненного цикла растений. Проект спроектирован по принципу **Offline–First** – ключевые данные хранятся локально на устройстве пользователя, что обеспечивает высокую скорость работы и полную автономность в условиях нестабильного интернет–соединения.

---

## ✨ Ключевые возможности системы

*   **🤖 AI–диагностика (Vision)** – визуальный анализ патологий по фотографиям с помощью модели **GigaChat–Max**. Система выявляет болезни и дает пошаговый протокол лечения.
*   **📅 Динамический календарь ухода** – интеллектуальный планировщик, который рассчитывает график полива на 30 дней вперед. При подтверждении задачи система автоматически пересчитывает будущую сетку задач, адаптируясь под реальный ритм жизни растения.
*   **🩺 Цифровая паспортизация** – мгновенное получение ботанических характеристик через ИИ. База данных автоматически пополняется латинскими названиями, описаниями видов и требованиями к освещенности.
*   **📈 Мониторинг развития** – ведение журналов физического прогресса. Система позволяет фиксировать изменения роста в сантиметрах и сохранять фотографии для отслеживания динамики развития.
*   **📑 Экспертная отчетность** – программная генерация PDF–документов, включающих аналитику «Дисциплины ухода» и персональные рекомендации по улучшению состояния растений.

---

## 💻 Технологический стек

*   **Интерфейс**: Python + Flet (на базе Flutter engine)
*   **Интеллект**: GigaChat API (Lite для обработки текстов, Max для визуального анализа)
*   **База данных**: SQLite + SQLAlchemy 2.0
*   **Обработка медиа**: Pillow – автоматическая оптимизация и сжатие изображений перед отправкой в ИИ.
*   **Документация**: ReportLab – бинарная генерация PDF–файлов непосредственно на устройстве.

## 🚀 Порядок развертывания системы

Для корректной работы GreenThumb требуется установленный **Python версии 3.10** или выше.

### 1. Подготовка исходного кода 🏗️
Склонируйте репозиторий проекта на ваше локальное устройство:
```bash
git clone https://github.com/equuuch/GreenThumb.git
cd GreenThumb
```

### 2. Настройка окружения 📦
Создайте изолированное виртуальное окружение для управления зависимостями:
```bash
python -m venv venv

# Активация для Windows:
venv\Scripts\activate

# Активация для Linux/macOS:
source venv/bin/activate

# Установка необходимых библиотек
pip install -r requirements.txt
```

### 3. Конфигурация доступа к API (.env) 🔑
Создайте в корневом каталоге файл `.env` и внесите в него данные для авторизации в GigaChat API:
```env
GIGA_CREDS=ваш_ключ_авторизации_в_base64
GIGA_CLIENT_ID=ваш_идентификатор_клиента
GIGA_SCOPE=GIGACHAT_API_PERS
DATABASE_URL=sqlite:///greenthumb.db
```

### 4. Ресурсы и системные шрифты 🔡
*   Убедитесь в наличии файла `assets/fonts/DejaVuSans.ttf` – он критически важен для корректного отображения кириллицы в PDF–отчетах.
*   Папки для хранения медиафайлов (`assets/plants` и `assets/logs`) будут созданы автоматически при первом запуске сервиса.

### 5. Инициализация базы данных 🏁
Перед первым запуском необходимо создать структуру таблиц и наполнить глобальный справочник растений:
```bash
python seed.py
```

Теперь система готова к работе. Запустите графическую оболочку командой:
```bash
flet run main.py
```

## 📂 Структура проекта

*   `main.py` – точка входа в приложение и код графического интерфейса.
*   `services/` – логика бизнес–процессов (расчет календаря, взаимодействие с ИИ, генерация отчетов).
*   `database/` – описание моделей данных и управление сессиями SQLAlchemy.
*   `assets/` – шрифты, системные иконки и архив фотографий растений пользователя.
*   `docs/` – пакет технической документации проекта.
